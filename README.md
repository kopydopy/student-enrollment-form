# Student Enrollment System

Responsive student enrollment form built with HTML, CSS, and JavaScript validation. Hosted with GitHub Pages.

## Local preview

Open `index.html` in a browser.

## Deploy to GitHub Pages

1. Push this project to the `main` branch.
2. On GitHub, open **Settings → Pages**.
3. Set **Source** to **Deploy from a branch**, then choose `main` and `/ (root)`.
4. The live site is:

`https://<your-username>.github.io/student-enrollment-form/`
Objectives: This lab activity aims to refresh students' foundational web development skills by creating a responsive student enrollment form with HTML, CSS, and JavaScript validation. Students will also learn to deploy their website using GitHub Pages, introducing them to version control and web hosting fundamentals.

Instructions:

Create and deploy a Student Enrollment Form website using HTML, CSS, JavaScript, and Github.

HTML Structure
Create index.html with enrollment form
Form Fields:
Student ID (text, required, min 5 characters)
Prefix (text, optional, min 2 characters)
First Name (text, required, min 3 characters)
Middle Name (text, optional, min 2 characters)
Last Name (text, required, min 2 characters)
Suffix (text, optional, min 2 characters)
Email (email, required)
Course (dropdown: BSIT, BSCS, BMMA, BSAIS)
If BSIT, add major (option: Net Sec, Web Tech, ERP)
Year Level (dropdown: 1st-3rd Year)
Submit Button
Additional:
Page Title: "Student Enrollment System".
Table or Section to display submitted data.

CSS Styling
Create style.css with
Style Inputs (padding, border, border-radius)
Style Button with hover effect
Responsive Design (Mobile Friendly)
Professional Layout and Color Scheme

JavaScript Validation
Create script.js with
Prevent default form submission
Validate all fields (Student ID, Name, Email, Course, Year)
Show error message in red
Clear errors on input
Show success message
Display submitted data in table format below the form

Deployment
Deploy it with github 
Upload and host the website using Github Pages
Copy the live url and submit it on canvas
