# Student Enrollment System

Responsive student enrollment form built with HTML, CSS, and JavaScript validation. Hosted with GitHub Pages.

## Local preview

Open `index.html` in a browser.

## Deploy to GitHub Pages

1. Push this project to the `main` branch.
2. On GitHub, open **Settings → Pages**.
3. Set **Source** to **Deploy from a branch**, then choose `main` and `/ (root)`.
4. The live site is:

`https://<your-username>.github.io/student-enrollment-form/`
